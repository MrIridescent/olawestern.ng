Here is the complete end-to-end Developer Workflow and Technical Specification for building the official campaign website for Hon. Folorunso Olaitan Segun (Ola Western), APC candidate for Amuwo-Odofin Constituency I.
1. Technical Stack & Systems Architecture
To ensure high performance across mobile devices in Lagos, low bandwidth consumption, tight security, and real-time synchronization with the Campaign War Room CRM, the web platform uses a headless, jamstack architecture.
* Frontend Framework: Next.js 14+ (App Router, Server-Driven Rendering, TypeScript).
* Styling & Design System: Tailwind CSS, Shadcn UI, Framer Motion (lightweight animations).
* Database & Auth: Supabase (PostgreSQL, Row Level Security, Edge Functions) for storing constituent registrations and contact inquiries.
* Content Management System (CMS): Payload CMS or Strapi (Headless CMS allowing the campaign press team at 32 Road to publish news and speeches without developer intervention).
* Hosting & Deployment: Vercel (Edge Network) with automated GitHub CI/CD integration.
* Integrations & Webhooks:
   * WhatsApp Business API: Webhooks forwarding voter registrations directly to the War Room assistant (+234 904 125 8180 / +234 803 400 5708).
   * Media Hosting: Cloudinary or AWS S3 (optimized image delivery).
   * Maps & Geolocation: Mapbox GL / Google Maps API (for ward and polling unit locating across Festac I, II, III, and Mile 2).

3. Database Schema (Supabase PostgreSQL)






SQL
-- Create Volunteers Table for Ward & Polling Unit Synchronization
CREATE TABLE volunteers (
   id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
   created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
   full_name TEXT NOT NULL,
   phone_number TEXT NOT NULL UNIQUE,
   email TEXT,
   ward_location TEXT NOT NULL CHECK (ward_location IN ('Festac I', 'Festac II', 'Festac III', 'Mile 2 / Housing Estate')),
   address_street TEXT,
   polling_unit_code TEXT,
   primary_concern TEXT, -- E.g., 'Road Infrastructure', 'Drainage', 'Youth/SME Empowerment'
   status TEXT DEFAULT 'pending_verification'
);

-- Enable Row Level Security (RLS)
ALTER TABLE volunteers ENABLE ROW LEVEL SECURITY;

-- Allow public insertion (for website visitors)
CREATE POLICY "Enable insertion for website visitors" ON volunteers 
FOR INSERT WITH CHECK (true);

Phase 4: API Route Implementation & WhatsApp CRM Sync (Days 9–10)
Create app/api/volunteer/route.ts to process volunteer forms, save them to PostgreSQL, and trigger a WhatsApp message to both the campaign war room and the constituent:






TypeScript
import { NextResponse } from 'next/server';
import { createClient } from '@supabase/supabase-js';

const supabase = createClient(
 process.env.NEXT_PUBLIC_SUPABASE_URL!,
 process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
);

export async function POST(request: Request) {
 try {
   const body = await request.json();
   const { fullName, phoneNumber, wardLocation, addressStreet, primaryConcern } = body;

   // 1. Insert lead into Supabase DB
   const { data, error } = await supabase
     .from('volunteers')
     .insert([
       { 
         full_name: fullName, 
         phone_number: phoneNumber, 
         ward_location: wardLocation, 
         address_street: addressStreet, 
         primary_concern: primaryConcern 
       }
     ]);

   if (error) throw error;

   // 2. Forward lead directly to War Room CRM Endpoint
   await fetch(process.env.WAR_ROOM_WEBHOOK_URL!, {
     method: 'POST',
     headers: { 'Content-Type': 'application/json' },
     body: JSON.stringify({ fullName, phoneNumber, wardLocation, addressStreet, primaryConcern })
   });

   // 3. Send automated WhatsApp confirmation via Meta Cloud API
   await fetch(`https://graph.facebook.com/v18.0/${process.env.WHATSAPP_PHONE_NUMBER_ID}/messages`, {
     method: 'POST',
     headers: {
       'Authorization': `Bearer ${process.env.WHATSAPP_CLOUD_API_TOKEN}`,
       'Content-Type': 'application/json'
     },
     body: JSON.stringify({
       messaging_product: "whatsapp",
       to: phoneNumber,
       type: "template",
       template: {
         name: "campaign_welcome_ola_western",
         language: { code: "en" },
         components: [
           {
             type: "body",
             parameters: [{ type: "text", text: fullName }]
           }
         ]
       }
     })
   });

   return NextResponse.json({ success: true, message: "Volunteer registered successfully!" });
 } catch (err: any) {
   return NextResponse.json({ success: false, error: err.message }, { status: 500 });
 }
}
